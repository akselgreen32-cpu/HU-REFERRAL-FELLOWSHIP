✨ About

HU-CMHS Evangelical Christian Students Fellowship is a Christian student fellowship at Hawassa University College of Medicine & Health Sciences.

The website provides information about the fellowship, its teams, mission, leadership, events, weekly schedule, and ways to connect and get involved.

🚀 Features

- Responsive design for mobile, tablet, and desktop
- English and Amharic language support
- Light and dark mode
- Fellowship information and history
- Teams and committees
- Events and activities
- Mission and statement of faith
- Leadership information
- Weekly fellowship schedule
- Contact and social media links
- Donation information
- Lightweight and fast static website

🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive design
- No frontend framework or unnecessary dependencies
